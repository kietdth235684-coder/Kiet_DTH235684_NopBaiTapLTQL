🔐 Đăng nhập & Phân quyền

Khởi động phần mềm

Chạy file QuanLyBanHang.exe. Cửa sổ đăng nhập xuất hiện tự động.

Nhập thông tin đăng nhập

Điền Tên đăng nhập và Mật khẩu, sau đó nhấn Đăng nhập hoặc Enter.

Hệ thống phân quyền tự động

Tài khoản Quản lý mở khóa toàn bộ chức năng. Tài khoản Nhân viên chỉ được truy cập Khách hàng, Hóa đơn và Báo cáo.

💡 Để đăng xuất, vào menu Hệ thống → Đăng xuất. Tất cả cửa sổ con sẽ tự đóng.

🗂️ Các chức năng Quản lý

Chức năngMenu truy cậpMô tả
Loại sản phẩmQuản lý → Loại sản phẩm…Thêm / sửa / xóa danh mục loại sản phẩm.
Hãng sản xuấtQuản lý → Hãng sản xuất…Quản lý danh sách nhà sản xuất.
Sản phẩmQuản lý → Sản phẩm…CRUD sản phẩm; hỗ trợ tìm kiếm, lọc.
Khách hàngQuản lý → Khách hàng…Quản lý danh sách khách hàng.
Nhân viênQuản lý → Nhân viên…Tạo / cập nhật tài khoản nhân viên (chỉ Quản lý).
Hóa đơnQuản lý → Hóa đơn bán hàng…Lập hóa đơn, thêm chi tiết, in hóa đơn.

Thao tác cơ bản trên các form quản lý

Thêm mới

Nhấn nút Thêm, điền thông tin vào các ô, nhấn Lưu để xác nhận.

Sửa

Chọn dòng dữ liệu cần sửa trong danh sách, nhấn Sửa, chỉnh thông tin rồi nhấn Lưu.

Xóa

Chọn dòng cần xóa, nhấn Xóa. Hệ thống yêu cầu xác nhận trước khi xóa.

Tìm kiếm

Nhấn Tìm kiếm, nhập từ khóa vào hộp thoại, danh sách tự lọc kết quả.

Xuất Excel

Nhấn Xuất Excel, chọn vị trí lưu file. Dữ liệu được xuất theo định dạng .xlsx.

🧾 Lập và In Hóa đơn

Mở form Hóa đơn

Vào Quản lý → Hóa đơn bán hàng…

Lập hóa đơn mới

Nhấn Lập hóa đơn. Chọn Nhân viên, Khách hàng, Ngày lập. Thêm từng sản phẩm bằng cách nhấn Thêm sản phẩm, chọn sản phẩm, nhập số lượng và đơn giá.

Lưu hóa đơn

Nhấn Lưu để ghi vào CSDL. Tổng tiền được tính tự động.

In hóa đơn

Chọn hóa đơn trong danh sách, nhấn In hóa đơn. Cửa sổ xem trước in mở ra với đầy đủ thông tin người mua, người bán và chi tiết hàng hóa.

🚀 Hướng dẫn cài đặt

Cài đặt .NET 8 Desktop Runtime

Tải từ dotnet.microsoft.com và chạy trình cài đặt.

Cài đặt SQL Server Express

Cài đặt SQL Server Express và bật chế độ Windows Authentication.

Tạo CSDL

Mở SSMS, chạy file QLBH_v2.0.sql để tạo và nhập dữ liệu mẫu vào CSDL QLBH.

Chạy phần mềm

Giải nén file cài đặt, chạy QuanLyBanHang.exe. Đăng nhập với tài khoản quản trị viên.
